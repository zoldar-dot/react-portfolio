# Akolawole Abdulazeez Portfolio

A responsive personal portfolio website built with React JS for Project 13 from the New Horizon React project assignment.

## Project description
This portfolio website presents a creative developer and designer with a modern home section, an about page, a work showcase, and a contact form with validation. The site uses React Router for page navigation and state-based interactions to make the experience feel dynamic and interactive.

## Technologies used
- React JS
- Vite
- React Router
- HTML
- CSS

## Installation
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run:
   npm install
4. Start the app:
   npm run dev

## Project highlights
- Responsive layout across mobile, tablet, and desktop screens
- Reusable content cards built with JavaScript arrays and .map()
- Contact form with validation and success feedback
- React Router navigation between pages
- A polished portfolio aesthetic for a modern personal brand

## Live deployment
Deploy the project to Netlify, Vercel, or Render and add the public URL to the project submission form.
